The loop改善循環

Nothing ships unmeasured.沒有量測，就不發佈。

  1. SpecSpecspec.yaml is the source of truthspec.yaml 是唯一真實來源
  2. Compile編譯Claude writes SKILL.md + draft evalsClaude 產生 SKILL.md 與評測草稿
  3. Linthouse rules, tracked waivers規則檢查，豁免可追蹤
  4. Eval評測with vs. without the skill有 vs. 沒有 skill
  5. Ship發佈tiered plugin marketplace分級的 plugin marketplace
  6. Measure量測calls, cost per call, errors呼叫數、單次成本、錯誤
  7. Papercutagents file what brokeagent 回報哪裡壞了
  8. Fix修正regression case → recompile回歸案例 → 重新編譯

What's inside功能

One CLI for the whole skill lifecycle.一個 CLI，涵蓋 skill 的完整生命週期。

⌘

Spec compilerSpec 編譯器

sf compile turns a spec into a lint-clean SKILL.md plus draft eval cases, feeding lint failures back to the model. Nothing is overwritten without --apply.sf compile 把 spec 編譯成通過 lint 的 SKILL.md 與評測草稿，並把 lint 失敗回饋給模型。沒有 --apply 就不會覆寫任何東西。

◎

Evals with a baseline含對照組的評測

Runs Claude Code's own claude plugin eval with and without the skill; pass rates with 95% intervals.以 Claude Code 自己的 claude plugin eval 比較有無 skill，回報通過率與 95% 信賴區間。

✂

Ablation & model bench消融與模型基準

Which sections earn their tokens; the cheapest model that clears the bar.哪些段落值得它的 token；達標中最便宜的模型。

◔

Local telemetry本機遙測

Hooks + a tiny OTLP collector on 127.0.0.1. Cost per skill from skill.name. No prompts recorded.Hooks 加上監聽 127.0.0.1 的小型 OTLP collector，依 skill.name 算出每個 skill 的成本。不記錄 prompt。

✎

Papercuts

Agents file structured friction reports; one command turns a report into a failing regression case.Agent 提交結構化的問題回報，一個指令就能變成會失敗的回歸案例。

⇪

Ship anywhere, run on a schedule到處發佈，依排程執行

A Claude Code plugin marketplace, plus sf install for Codex, OpenCode and Gemini CLI. CI evals on every PR, nightly suites, and managed agents with outcome checks.Claude Code plugin marketplace，加上可安裝到 Codex、OpenCode、Gemini CLI 的 sf install。每個 PR 跑評測、每晚跑完整套件，以及帶成果檢查的託管 agent。

Quickstart快速開始

Use the skills, or build your own.使用現成 skill，或打造自己的。

Install in Claude Code在 Claude Code 安裝

/plugin marketplace add yennanliu/skill-factory-1
/plugin install sf-platform@skill-factory
/plugin install sf-core@skill-factory

Work on the repo開發本專案

git clone https://github.com/yennanliu/skill-factory-1
cd skill-factory-1 && uv sync
uv run sf --help
scripts/e2e_local.sh

A new skill in minutes幾分鐘做出新 skill

uv run sf new my-skill --goal "One sentence on what it achieves."
uv run sf compile my-skill --apply     # spec → SKILL.md + draft evals
uv run sf eval my-skill --runs 3       # with vs. without the skill
uv run sf build                        # → plugins/ + marketplace.json

Commands指令

Everything is one sf away.所有功能都在 sf 之下。

sf new · sf compile
scaffold a skill; compile its spec into SKILL.md + draft evals建立 skill；把 spec 編譯成 SKILL.md 與評測草稿
sf spec validate · sf lint
validate specs; lint against the house rules驗證 spec；依規則 lint
sf build · sf release
generate the marketplace; bump versions產生 marketplace；更新版本
sf eval
eval suites with a no-skill baseline含無 skill 對照組的評測
sf ablate · sf bench
what each section adds; cheapest passing model各段落的貢獻；達標中最便宜的模型
sf judge calibrate
LLM judge vs. your labels (Cohen's κ)LLM judge 與你的標註比對（Cohen's κ）
sf otel up · sf stats
local collector; calls, cost and errors per skill本機 collector；每個 skill 的呼叫、成本與錯誤
sf report · sf analyze
HTML report; costliest sessions and wasteHTML 報表；最貴的 session 與浪費
sf papercuts · sf search
triage agent reports; find an existing skill分流 agent 回報；搜尋既有 skill
sf install · sf agent run
install into Codex / OpenCode / Gemini; managed agents安裝到 Codex / OpenCode / Gemini；託管 agent
