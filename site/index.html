skill-factory is a small, Uber-style platform for Claude Code skills. Write a spec, compile it into a SKILL.md, lint it, evaluate it against a no-skill baseline, ship it as a plugin, measure what it costs per call, and let agents report what breaks.

The loop

Nothing is overwritten silently, nothing ships unmeasured.

  1. Specspec.yaml is the source of truth
  2. CompileClaude writes SKILL.md + draft evals
  3. Linthouse rules, waivers tracked
  4. Evalwith vs. without the skill
  5. Shipplugin marketplace, tiered
  6. Measurecalls, cost per call, errors
  7. Papercutagents file what broke
  8. Fixregression case → recompile

What's inside

Spec compiler

sf compile turns a spec into a lint-clean SKILL.md and draft eval cases, feeding lint failures back to the model. Uses your Claude Code login or the API.

Evals with a baseline

sf eval runs Claude Code's own claude plugin eval harness, with and without the skill, and reports pass rates with 95% intervals against the spec's bar.

Ablation & model bench

sf ablate removes one section at a time; sf bench finds the cheapest model that clears the bar; sf judge calibrate checks the LLM judge.

Telemetry, locally

Hooks plus a tiny OTLP collector on 127.0.0.1. Cost per skill comes from api_request.cost_usd grouped by skill.name. No prompts recorded.

Papercuts

An always-on skill lets agents file structured friction reports. sf papercuts promote turns one into a failing regression case.

Ship anywhere

A Claude Code plugin marketplace, plus sf install for Codex, OpenCode and Gemini CLI. CI, nightly evals and scheduled managed agents included.

Quickstart

Use the skills

/plugin marketplace add yennanliu/skill-factory-1
/plugin install sf-platform@skill-factory
/plugin install sf-core@skill-factory

Work on the repo

git clone https://github.com/yennanliu/skill-factory-1
cd skill-factory-1
uv sync
uv run sf --help
scripts/e2e_local.sh   # end-to-end check

A new skill in minutes

uv run sf new my-skill --goal "One sentence on what it achieves."
# edit skills/my-skill/spec.yaml: triggers, outputs, tools
uv run sf compile my-skill --apply     # spec → SKILL.md + draft evals
uv run sf eval my-skill --runs 3       # with vs. without the skill
uv run sf build                        # → plugins/ + marketplace.json

Commands
